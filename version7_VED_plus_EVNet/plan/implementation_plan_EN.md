# Version 7: VED + EVNet Fixed — Implementation Plan (English)

## Overview

This version reproduces and extends the EVNet-enhanced EEG-to-image retrieval pipeline from the reference implementation (`temp/yliu674/v5_evnet`). It runs four experiments covering two blur level configurations and two training data strategies, fulfilling Course Task 1 (EEG-to-image retrieval).

---

## Architecture

### Model: Brain_Visual_Encoder_EEG

The model encodes raw EEG signals and retrieves matched images via contrastive learning (CLIP-style loss).

**EEG branch:**
- Spatial convolution (`Conv2dWithAbs`, 25 filters over 63 channels)
- Temporal MLP: 250 → 200 → 200 (ELU + Dropout)
- Linear adapter: 25×200 → 1024

**Image branch — Multi-scale blur features:**
- Pre-computed with OpenCLIP RN50 at 8 or 12 Gaussian blur levels
- Aggregated with learnable attention weights (`learned_scale`) → 1024-dim vector

**EVNet fixed fusion:**
- Pre-computed EVNet features: EVNetFrontEnd (SubcorticalBlock + VOneBlock, all weights frozen) → RN50 → 1024-dim
- Fusion: `fused = softmax(fusion_logits)[0] × blur_agg + softmax(fusion_logits)[1] × evnet_feat`
- Fusion MLP (`fusion_adapter`): 1024 → 768 → 1024
- `fusion_logits` initialized as `[0.7, 0.3]` and learned during training

"Fixed" means the EVNet neural-biological frontend weights are never updated — only the fusion weights and adapters are trained.

## Experiment Design

### Phase A — 95/5 Split (val-based checkpoint selection)

- 95% of `train.pt` used for training, 5% as validation
- Best checkpoint selected by validation Top-1 accuracy
- Evaluate on full test set

### Phase B — Full Training (no val split)

- 100% of `train.pt` used for training, no validation set
- `select` checkpoint = last epoch; `best` checkpoint = best test epoch across all epochs
- Evaluate on full test set

### Four Experiments

| Script | Config | Phase |
|---|---|---|
| `02_train_8blur_evnet_split.sh` | 8 blur + EVNet fixed | A (split) |
| `03_train_12blur_evnet_split.sh` | 12 blur + EVNet fixed | A (split) |
| `04_full_train_8blur_evnet.sh` | 8 blur + EVNet fixed | B (full) |
| `05_full_train_12blur_evnet.sh` | 12 blur + EVNet fixed | B (full) |

All experiments: 10 seeds (21–30), 200 epochs, batch size 1024, lr 0.001, AdamW optimizer.

## Discrepancy Analysis

If results differ from reference by more than ~2%:

1. **Image key mismatch**: The blur PT files (from version5_VED) and EVNet PT files (from version7) must use the same relative image path format (`train_images/category/file.jpg`). Both are generated by the same `collect_image_paths` function so they should match. Verify:
   ```python
   import torch
   blur = torch.load('output/Image_feature/MultiBlur_RN50_train.pt', weights_only=False)
   evnet = torch.load('output/Image_feature/EVNet_RN50_train.pt', weights_only=False)
   print(len(set(blur['1'].keys()) & set(evnet.keys())))
   ```

2. **EVNet truly fixed**: Confirm `requires_grad=False` for all `EVNetFrontEnd` parameters (already enforced in `process_image_course.py`).

3. **Seed alignment**: `set_seed()` sets both `torch.manual_seed` and `np.random.seed` ✓

4. **Blur set correctness**: 8-level = `['l_1','l_3','l_15','l_21','l_33','l_45','l_57','l_63']` (matching reference) ✓

5. **EEG data**: Verify `Preprocessed_data_250Hz_whiten` is the correct preprocessing variant used by the reference.
