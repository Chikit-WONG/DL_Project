# VisualEEGDecoding 课程版运行说明

## 1. 环境要求

建议优先尝试复用 `test` conda 环境；如果其中缺少 `diffusers`、`transformers` 或 `scikit-image`，再新建环境。

推荐 Python 版本：**Python 3.10**。

```bash
conda create -n ved python=3.10 -y
conda activate ved
pip install -r requirements.txt
```

## 3. Task 1：检索流程

进入仓库目录：

```bash
cd /path/to/version5_VED
```

运行 task 1：

```bash
python scripts/run_course_pipeline.py --data_root /path/to/image-eeg-data --clip_checkpoint /path/to/CLIP-RN50-openai/open_clip_pytorch_model.bin
```

如果你那边是可以直接 `python` 调 GPU 的机器，更方便的方式是：

```bash
bash run_task1_direct.sh
```

这条命令会自动：

1. 建立课程数据符号链接
2. 生成 `output/Image_feature/` 下的 blur 特征
3. 训练 task 1 EEG encoder

如果只做 smoke test：

```bash
python scripts/run_course_pipeline.py --data_root /path/to/image-eeg-data --clip_checkpoint /path/to/CLIP-RN50-openai/open_clip_pytorch_model.bin --epoch 1 --n_seeds 1 --first_seed 999
```

## 4. Task 2：重建流程

task 2 需要一个 task 1 checkpoint 作为初始化：

```bash
python scripts/run_task2_pipeline.py \
  --data_root /path/to/image-eeg-data \
  --clip_checkpoint /path/to/CLIP-RN50-openai/open_clip_pytorch_model.bin \
  --task1_ckpt /path/to/task1_select_checkpoint.pth
```

如果你那边是可以直接 `python` 调 GPU 的机器，更方便的方式是：

```bash
bash run_task2_direct.sh
```

这个脚本会自动在 `output/logs/main_eeg_course/` 下找最新的 `*_select.pth`。如果你想手动指定 checkpoint，可以：

```bash
TASK1_CKPT=/绝对路径/到/checkpoint.pth bash run_task2_direct.sh
```

这条命令会自动：

1. 基于 task 1 checkpoint 做语义微调
2. 用 EEG 检索训练图像并聚合出 prompt 类别
3. 用固定 prompt + top-1 参考图 + IP-Adapter 生成测试集重建图像
4. 评估 `SSIM` 和 `CLIP`

task 2 smoke test：

```bash
python scripts/run_task2_pipeline.py \
  --data_root /path/to/image-eeg-data \
  --clip_checkpoint /path/to/CLIP-RN50-openai/open_clip_pytorch_model.bin \
  --task1_ckpt /path/to/task1_select_checkpoint.pth \
  --epoch 1 --n_seeds 1 --first_seed 999
```

## 5. 输出位置

所有结果都在 `output/` 下：

```text
output/
  Image_feature/
  logs/main_eeg_course/
  task2/
```

其中 task 2 会保存：

- 语义微调 checkpoint
- 文本 prototype cache
- 检索元数据
- 生成图像
- ground-truth 图像
- 评估 JSON/CSV

## 6. 定性拼图

如果要生成 8-12 个定性例子用的拼图：

```bash
python scripts/make_task2_qualitative_grid.py \
  --real-root output/task2/pipeline_runs/<run>/reconstructions/seed21/ground_truth \
  --fake-root output/task2/pipeline_runs/<run>/reconstructions/seed21/generated \
  --output output/task2/pipeline_runs/<run>/qualitative_seed21.png
```

## 7. SLURM 脚本

提交脚本都在：

```text
version5_VED/slurm_scripts/
```

推荐顺序：

1. `02_gen_blur_features.sh`
2. `03_train_eeg.sh`
3. `04_run_task2_smoke.sh`
4. `05_run_task2_full.sh`

默认先用 `debug` 做 smoke test；完整任务如果时间不够，再改到 `long_gpu` 或其它排队更快的 GPU 分区。

补充一点：现在这些脚本启动时会自动清理代理环境变量，并在有 `unclash` 函数时自动调用它。所以如果你 shell 里之前开过 Clash 代理，通常不需要再手动处理一次。
