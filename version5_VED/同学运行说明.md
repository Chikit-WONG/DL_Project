# VisualEEGDecoding 课程版运行说明

## 1. 环境要求

建议使用 **Python 3.10**。目标机器需要有 NVIDIA GPU，A800 可以直接运行。

```bash
conda create -n ved python=3.10 -y
conda activate ved
pip install -r requirements.txt
```

如果目标 HPC 的 CUDA/PyTorch 需要特殊安装方式，请先按该机器官方方式安装 `torch` 和 `torchvision`，然后再执行：

```bash
pip install -r requirements.txt
```

## 2. 数据和模型准备

代码仓库不要提交数据、模型权重、训练日志或生成的 `.pt` 特征文件。请在目标 HPC 上另外准备：

1. 课程数据目录 `image-eeg-data`
2. OpenCLIP RN50 权重文件 `open_clip_pytorch_model.bin`

课程数据目录需要包含这些路径：

```text
image-eeg-data/
  training_images/
  test_images/
  converted_for_cogcappro/ThingsEEG/Preprocessed_data_250Hz_whiten/sub-01/train.pt
  converted_for_cogcappro/ThingsEEG/Preprocessed_data_250Hz_whiten/sub-01/test.pt
```

RN50 权重可以在有网络的机器上下载：

```bash
python scripts/download_rn50.py --save_dir /path/to/CLIP-RN50-openai
```

下载完成后会得到：

```text
/path/to/CLIP-RN50-openai/open_clip_pytorch_model.bin
```

如果目标 HPC 不能联网，就在别的机器下载后传过去。

## 3. 一行命令运行

进入仓库根目录，例如：

```bash
cd /path/to/version5_VED
```

然后运行：

```bash
python scripts/run_course_pipeline.py --data_root /path/to/image-eeg-data --clip_checkpoint /path/to/CLIP-RN50-openai/open_clip_pytorch_model.bin
```

这条命令会自动完成：

1. 在 `data/things-eeg/` 下创建数据符号链接
2. 在 `output/Image_feature/` 下生成 12 个 blur level 的 RN50 图像特征
3. 训练 EEG encoder，默认 10 个随机种子，seed 为 21 到 30
4. 在 `output/logs/` 下保存训练日志、模型权重和指标 CSV

## 4. 常用快速测试命令

第一次跑建议先做一个 1 epoch、1 seed 的 smoke test：

```bash
python scripts/run_course_pipeline.py --data_root /path/to/image-eeg-data --clip_checkpoint /path/to/CLIP-RN50-openai/open_clip_pytorch_model.bin --epoch 1 --n_seeds 1 --first_seed 999
```

如果图像特征已经生成，只想重新训练：

```bash
python scripts/run_course_pipeline.py --data_root /path/to/image-eeg-data --clip_checkpoint /path/to/CLIP-RN50-openai/open_clip_pytorch_model.bin --skip_features
```

如果只想生成图像特征，不训练：

```bash
python scripts/run_course_pipeline.py --data_root /path/to/image-eeg-data --clip_checkpoint /path/to/CLIP-RN50-openai/open_clip_pytorch_model.bin --skip_train
```

## 5. 输出位置

所有运行产物都会放在 `output/` 目录下，方便运行结束后整体打包或 rsync。

图像特征会保存在：

```text
output/Image_feature/
  MultiBlur_RN50_train.pt
  MultiBlur_RN50_test.pt
```

训练日志和结果会保存在：

```text
output/logs/main_eeg_course/Brain_Visual_Encoder_EEG/<时间戳>/
```

训练完成后汇总指标：

```bash
python scripts/evaluate_course_metrics.py
```

输出会包含课程需要的 Top-1 和 Top-5 mean ± std。

运行结束后，可以直接同步整个输出目录，例如：

```bash
rsync -avP /path/to/version5_VED/output/ your_hpc:/path/to/save/version5_VED_output/
```
