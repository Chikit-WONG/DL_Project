在main_eeg_course.py中，  
第425行左右，有设置BLUR_LEVELS的行，其中12个的就是12个level，只有一个l_1的就是没有blur  
```python
BLUR_LEVELS = ['l_1', 'l_3', 'l_9', 'l_15', 'l_21', 'l_27', 'l_33', 'l_39', 'l_45', 'l_51', 'l_57', 'l_63'] # 12
BLUR_LEVELS = ['l_1', 'l_3', 'l_15', 'l_21', 'l_33', 'l_45', 'l_57', 'l_63'] # 8
BLUR_LEVELS = ['l_1', 'l_63'] # 2
BLUR_LEVELS = ['l_1'] # no blur
```
可以注释掉其他的行，只保留一个BLUR_LEVELS的设置，就可以了。
  
在运行main_eeg_course.py时，如果加上 --use_evnet参数，就会在已有的blur特征的基础上使用EVNet特征。
